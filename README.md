# 🛒 Online Store Registration System
<img width="1920" height="939" alt="image" src="https://github.com/user-attachments/assets/62deacb1-f7cd-4892-a2e1-115b50516c81" />


A simple **user registration system** built with **Python and Streamlit**.  
This application demonstrates how to validate user input, handle form data, and apply a basic password encryption technique.

The project was created as a learning exercise to practice **form validation, input handling, and basic security concepts** while building an interactive web interface using Streamlit.

---

## 🚀 Features

- Full name validation (requires first and last name)
- Email format validation
- Kosovo phone number validation
- Address and postal code validation
- Password confirmation check
- Basic password encryption demonstration
- Interactive user interface using Streamlit
- Real-time validation feedback messages

---

## 🧰 Technologies Used

- **Python**
- **Streamlit**
- Basic **Caesar Cipher encryption algorithm** (for educational purposes)

---

## ▶️ Running the Application

Install dependencies:

pip install streamlit

Run the application:

streamlit run app.py
